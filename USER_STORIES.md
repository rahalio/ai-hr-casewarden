# Casewarden — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Caseworker

- As a caseworker, I want my caseload ordered by risk of harm and statutory deadline rather than by date received, so that my day is spent where the duty is greatest.
- As a caseworker, I want the automated assessment to show me which facts and which rule version produced its conclusion, so that I can accept it, correct it, or override it with reasons.
- As a caseworker, I want to record an override and know it counts as feedback on the model rather than as a mark against me, so that I report problems instead of working around them.
- As a caseworker, I want a single view of what partner agencies have lawfully shared about a person, so that I am not phoning three organisations to assemble a picture that already exists.

### Duty-desk and safeguarding lead

- As a safeguarding lead, I want every concern that crosses a statutory threshold escalated regardless of its triage score, so that the model can order my queue but never remove a duty from it.
- As a safeguarding lead, I want to see time to first contact against target for every open risk signal, so that I can reallocate the team before a deadline is breached rather than after.
- As a duty manager, I want to reopen and re-grade a case when new information arrives, with the previous grading preserved, so that decisions made on the old facts remain explainable.

### Eligibility and appeals officer

- As an eligibility officer, I want determination types classified as standard or complex with published accuracy and overturn baselines, so that I know which work the engine may issue and which it may only prepare.
- As an appeals officer, I want the reconsideration bundle assembled automatically from the determination record, including the reasons and the evidence relied on, so that statutory deadlines are met without a manual trawl.
- As an appeals officer, I want overturn rates reported per determination type and per rule version, so that a systematic error surfaces as a pattern instead of as a run of individual losses.

### Information governance officer

- As an information governance officer, I want every cross-agency disclosure gated on a recorded agreement, gateway and purpose, so that a request outside the gateway fails rather than being granted informally.
- As an information governance officer, I want a field-level disclosure log per person, so that a subject access request or an ombudsman enquiry can be answered from the system.
- As an information governance officer, I want fraud-risk models held in a separate governance track with bias testing by protected characteristic, so that the agency can answer the question it will certainly be asked.

### Citizen, carer or advocate

- As a citizen, I want to know when automation was involved in a decision about me and to receive reasons I can actually contest, so that the appeal route is real.
- As a carer, I want to be offered support at the point my circumstances change rather than after a crisis, and to be able to turn that contact off, so that proactive help does not feel like surveillance.
- As an advocate, I want to act on a person's behalf across application, determination and appeal with recorded authority, so that the person's case does not stall because they cannot navigate it alone.
